Context Dumps
=============

This folder collects working notes, retrospectives, and context for changes
made during hands-on debugging and release operations. It’s intentionally
separate from user-facing docs so we can freely capture rationale, tradeoffs,
and operational details.

Conventions
- One file per workstream or incident, named `YYYY-MM-DD_<slug>.md`.
- Keep it concrete: what we saw, what we changed, how we verified, next steps.
- Avoid secrets; reference environment variables or dashboards without pasting
  sensitive values.
